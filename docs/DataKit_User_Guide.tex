\chapter*{Preface}
DataKit is a Python library that provides a high-intent, safety-guaranteed interface over NumPy, Pandas, Matplotlib, and Seaborn. It eliminates silent failures, implicit rank-broadcasting errors, state-bleed in Matplotlib, and boilerplate code in exploratory data analysis (EDA), cleaning, visualization, ML preparation, and reporting.

\chapter{Architectural Philosophy \& Safety-First Paradigm}

\section{Core Design Principles}
DataKit adheres to five fundamental design pillars:

\begin{enumerate}
    \item \textbf{Explicit Safety over Silent Convenience}: Destructive data transformations require explicit \texttt{confirm=True} confirmation gates. Implicit rank-broadcasting operations that generate unwanted high-dimensional outer products are intercepted and flagged.
    \item \textbf{Immutable Pipeline Ergonomics}: Methods that transform data (such as \texttt{clean()}) return a new \texttt{DataKit} instance containing a deep copy, preserving original dataset state.
    \item \textbf{Pure Object-Oriented Visualizations}: Visual rendering operates exclusively on Matplotlib \texttt{Figure} and \texttt{Axes} instances without global \texttt{pyplot} state-bleed.
    \item \textbf{Three-Part Explained Exceptions}: All error messages adhere to a 3-part structure: \textit{what happened}, \textit{why it matters}, and \textit{suggested fix}.
    \item \textbf{Thin Orchestration Layer}: DataKit orchestrates underlying scientific stack components without creating heavy wrapper objects over primitive data structures.
\end{enumerate}

\chapter{Core DataKit Engine \& File Loading}

\section{The Auto-Detect Reader: dk.read()}
DataKit provides the \texttt{dk.read(source)} function to auto-detect file formats from extensions without requiring manual format parameters.

\begin{lstlisting}[language=python]
import datakit as dk

# Auto-detect and load CSV, Excel, Parquet, JSON, or DataFrames
data = dk.read("insurance.csv")
data_excel = dk.read("data.xlsx")
data_parquet = dk.read("data.parquet")

# Access live DataFrame escape hatch
df_live = data.df
\end{lstlisting}

\section{Format Dispatch Matrix}
DataKit implements format dispatch based on file extensions:
\begin{itemize}
    \item \texttt{.csv}: Dispatches to \texttt{pandas.read\_csv()}.
    \item \texttt{.xlsx}, \texttt{.xls}: Dispatches to \texttt{pandas.read\_excel()} (requires \texttt{openpyxl}).
    \item \texttt{.parquet}: Dispatches to \texttt{pandas.read\_parquet()} (requires \texttt{pyarrow}).
    \item \texttt{.json}: Dispatches to \texttt{pandas.read\_json()}.
\end{itemize}

\chapter{Broadcasting \& Safety Module (dk.safe)}

\section{Broadcasting Vulnerability Overview}
NumPy and Pandas automatically broadcast arrays of different ranks. Subtracting a 1D array of shape $(n,)$ from a 2D column vector of shape $(n, 1)$ silently produces a 2D matrix of shape $(n, n)$ rather than an element-wise operation.

\section{Safe Operations API}
\begin{lstlisting}[language=python]
import datakit as dk
import numpy as np

a = np.arange(5)          # Shape (5,)
b = np.arange(5)[:, None]  # Shape (5, 1)

# Issues ImplicitBroadcastWarning naming shapes (5,) and (5, 1) -> (5, 5)
res = dk.safe.subtract(a, b)

# Shape inspection pre-flight
shape_info = dk.safe.check_shapes(a, b)
print(shape_info.explanation)
\end{lstlisting}

\chapter{Quality Audit \& Guided Cleaning}

\section{The 7-Check Quality Audit}
Calling \texttt{data.audit()} runs 7 prioritized quality checks:
\begin{enumerate}
    \item \textbf{missing}: Identifies missing rates (>40\% critical, >10\% warning).
    \item \textbf{duplicates}: Detects duplicate rows (>10\% critical).
    \item \textbf{constant}: Warns on zero-variance columns.
    \item \textbf{cardinality}: Warns on categoricals with >50 unique values.
    \item \textbf{suspicious\_dtype}: Flags numeric-as-string object columns.
    \item \textbf{id\_like}: Identifies primary key columns.
    \item \textbf{leakage}: Detects target leakage correlations ($|r| \ge 0.98$).
\end{enumerate}

\section{Non-Destructive Cleaning}
\begin{lstlisting}[language=python]
# Confirmed cleaning with diff summary
cleaned = data.clean(missing="impute_median", duplicates="drop", confirm=True)
print(cleaned.last_clean_report.diff_summary())
\end{lstlisting}

df_flagged = outliers.to_dataframe(data.df, flag_column="_is_outlier")
